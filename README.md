# Climate Risk Prediction System

## Overview

Climate Risk Prediction System is an AI-powered web application that analyzes weather conditions and predicts potential climate risks such as rainfall, heatwaves, and storms. The system provides real-time weather information, 7-day forecasts, risk assessment, trend analysis, GPS-based location detection, and an AI Weather Assistant.

## Features

* Real-time weather monitoring
* 7-day weather forecast
* Climate trend analysis
* Rainfall prediction
* Heatwave risk detection
* Storm risk assessment
* GPS-based location detection
* AI Weather Assistant
* Interactive dashboard
* About page with project information

## Installation

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```
